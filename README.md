# QAZAQSTAN PUBLIC FINANCE MONITOR
### Аналитическая система мониторинга социальных расходов государственного бюджета РК (2021–2025)

Аналитический веб-интерфейс в стилистике передовой визуальной журналистики (*The Financial Times Visual Journalism, Bloomberg Graphics, Bundeshaushalt.de*) для исследования движения бюджетных средств Казахстана по **Разделу 06 («Социальная помощь и социальное обеспечение»)** в разрезе 20 регионов и видов социальных услуг.

Разработано по архитектуре **Pure Frontend (без бэкенда)** со статическими структурированными данными и поддержкой работы через протокол `file://`.

---

## Быстрый запуск

Просто откройте файл `index.html` двойным кликом в любом современном веб-браузере (Chrome, Edge, Firefox, Safari).

Никаких серверов, баз данных и установки Node.js не требуется!

## Ключевые возможности системы

### 1. 📅 Таймлайн и динамика по годам (2021–2025)
* **5 финансовых лет:** от 2021 года (3.98 трлн ₸) до 2025 года (6.05 трлн ₸, утвержденный план).
* **Метрика YoY (Year-over-Year):** процент изменения расходов год к году.
* **Макроэкономический контекст:** пояснительные редакционные сводки по каждому году (внедрение Социального кодекса, создание областей Абай, Жетісу и Ұлытау, индексация базовых выплат).
* **Автопроигрывание таймлайна (▶):** возможность запустить плавную смену лет и наблюдать эволюцию социальных ассигнований.

### 2. 🌊 Аналитические режимы визуализации
* **Потоки капитала (Sankey):** магистральное движение тенге от Госбюджета через республиканский центр и акиматы в конечные программы.
* **Иерархический Sunburst:** радиальная декомпозиция с плавным зумом по клику вглубь региона или программы.
* **Сетевой граф связей (Physics Graph):** интерактивная топологическая карта зависимостей с перетаскиваемыми узлами.
* **Реестр регионов:** подробный аналитический отчет по 20 регионам с подушевым финансированием, сортировкой колонок и поиском.

### 3. 🔍 Мастер-детализация и Инспектор региона
* Клик по любому региону на графике или в реестре открывает **боковую панель (Inspector Drawer)**, которая не сжимает график, а плавно выдвигается поверх.
* Включает бенчмарк к медиане по РК (например, `▲ +25% выше медианы по РК`), статус донор/субвенция, и мини-структуру местных расходов по 4 направлениям (АСП, МСУ/интернаты, реабилитация, занятость).
* Закрывается по клику или клавише `Esc`.

### 4. 🎨 Дизайн-система и Двойная тема (Light Editorial & Dark Obsidian)
* Полный отказ от шаблонных градиентов, избыточных теней и «карточного синдрома».
* **Светлая тема (Light Editorial):** тёплая бумага (`#FAF9F5`), прецизионные разделители 1px, высокая контрастность для чтения длинных отчетов.
* **Тёмная тема (Dark Obsidian):** глубокий обсидиановый минерал (`#0D1117`), контрастные флуоресцентные потоки, снижающие утомляемость глаз.
* Автоопределение по `prefers-color-scheme` и ручной тумблер с сохранением в `localStorage`.
* Шрифтовая триада:
  * **Newsreader** (антиква для заголовков и аналитических тезисов);
  * **Plus Jakarta Sans** (швейцарский гротеск для интерфейсных контролов);
  * **JetBrains Mono** (моноширинный шрифт с табличными цифрами `tabular-nums` для финансовых сумм).

## Структура файлов проекта

```text
budget/
├── index.html                        # Аналитический веб-интерфейс (Pure HTML/JS)
├── README.md                         # Документация проекта
├── REDESIGN_PLAN.md                  # Спецификация и план редизайна
├── styles/
│   └── tokens.css                    # Токены дизайн-системы (Light Editorial & Dark Obsidian)
├── docs/
│   ├── audit.md                      # Первичный аудит и дефекты интерфейса
│   └── baseline_numbers.json         # Эталонные финансовые показатели (2021-2025)
├── data/
│   ├── regions.json                  # 20 регионов РК (КАТО, население, статус донор/субвенция)
│   ├── social_categories.json        # Классификатор Раздела 06 ЕБК РК
│   ├── budget_social_multiyear.json  # Полная база данных за 2021–2025 гг. (JSON)
│   └── budget_data.js                # Офлайн-бандл данных для мгновенного запуска через file://
└── scripts/
    ├── generate_data.py              # Мульти-летний генератор и валидатор графовой модели
    └── parse_minfin.py               # Модуль парсинга официальных Excel-отчетов Минфина РК (Форма 1-Н / 2-Н)
```

## Обновление данных (для разработчиков)

Для повторной сборки базы данных или парсинга свежих отчетов Минфина РК:
```bash
# Перегенерация пятилетки данных через uv:
uv run scripts/generate_data.py

# Или через стандартный Python:
python scripts/generate_data.py

# Парсер отчетов Минфина:
uv run --with pandas,openpyxl,httpx scripts/parse_minfin.py --file "путь_к_файлу.xlsx"
```
