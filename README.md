# QAZAQSTAN PUBLIC FINANCE MONITOR
### Аналитическая система мониторинга социальных расходов государственного бюджета РК (2021–2025)

Аналитический веб-интерфейс уровня ведущих мировых изданий (*The Financial Times, Bloomberg, The Economist*) для исследования движения бюджетных средств Казахстана по **Разделу 06 («Социальная помощь и социальное обеспечение»)** в разрезе 20 регионов и видов социальных услуг.

Разработано по архитектуре **Pure Frontend (без бэкенда)** со статическими структурированными данными.

---

## Ключевые возможности системы

### 1. 📅 Таймлайн и динамика по годам (2021–2025)
* **5 финансовых лет:** от 2021 года (3.98 трлн ₸) до 2025 года (6.05 трлн ₸, утвержденный план).
* **Метрика YoY (Year-over-Year):** процент изменения расходов год к году.
* **Макроэкономический контекст:** пояснительные сводки по каждому году (внедрение Социального кодекса, создание областей Абай, Жетісу и Ұлытау, индексация базовых выплат).
* **Автопроигрывание таймлайна (▶):** возможность запустить динамическую смену лет и вживую наблюдать, как расширяются финансовые потоки Казахстана.

### 2. 🌊 Аналитические режимы визуализации
* **Потоки капитала (Sankey):** магистральное движение тенге от Госбюджета через республиканский центр и акиматы в конечные программы.
* **Иерархический Sunburst:** радиальная декомпозиция с плавным зумом по клику вглубь региона или программы.
* **Сетевой граф связей (Physics Graph):** интерактивная топологическая карта зависимостей с перетаскиваемыми узлами.
* **Реестр регионов:** подробный аналитический отчет по 20 регионам с подушевым финансированием и фильтрацией.

### 3. 🔍 Мастер-детализация и Инспектор региона
* Клик по любому региону на графике или в реестре открывает **боковую аналитическую панель (Inspector Drawer)** с точными цифрами по 4 направлениям (АСП, МСУ, реабилитация, занятость) и кнопкой фокусировки графа на выбранном регионе.

### 4. 🎨 Авторский дизайн без «ИИ-штампов»
* Полный отказ от неоновых фиолетовых рамок и шаблонов.
* Шрифтовая триада:
  * **Newsreader** (элегантный академический антиква-шрифт для заголовков и аналитических тезисов);
  * **Plus Jakarta Sans** (швейцарский гротеск для интерфейсных элементов);
  * **JetBrains Mono** (моноширинный шрифт с табличными цифрами для финансовых сумм).
* Цветовая палитра на основе глубокого обсидиана (`#080A0E`), государственного циан-оттенка (`#0284C7`), изумрудного для регионов-доноров (`#059669`) и теплого терракотового для субвенций (`#D97706`).

## Структура файлов проекта

```text
budget/
├── index.html                        # Редизайн аналитического веб-интерфейса
├── README.md                         # Документация проекта
├── data/
│   ├── regions.json                  # 20 регионов РК (КАТО, население, статус донор/субвенция)
│   ├── social_categories.json        # Классификатор Раздела 06 ЕБК РК
│   ├── budget_social_multiyear.json  # Полная база данных за 2021–2025 гг. (JSON)
│   └── budget_data.js                # Офлайн-бандл данных для мгновенного запуска через file://
└── scripts/
    ├── generate_data.py              # Мульти-летний генератор и валидатор графовой модели
    └── parse_minfin.py               # Модуль парсинга официальных Excel-отчетов Минфина РК (Форма 1-Н / 2-Н)
```

## Обновление данных через `uv`

В системе уже настроен менеджер пакетов `uv`:
```powershell
# Перегенерация пятилетки данных:
& "C:\Users\nkaba\.local\bin\uv.exe" run scripts/generate_data.py

# Парсер отчетов Минфина:
& "C:\Users\nkaba\.local\bin\uv.exe" run --with pandas,openpyxl,httpx scripts/parse_minfin.py --file "путь_к_файлу.xlsx"
```
