# QAZAQSTAN PUBLIC FINANCE MONITOR
### Аналитическая система мониторинга социальных расходов государственного бюджета РК (2021–2025)

Аналитический веб-интерфейс в стилистике передовой визуальной журналистики (*The Financial Times Visual Journalism, Bloomberg Graphics, Bundeshaushalt.de*) для исследования движения бюджетных средств Казахстана по **Разделу 06 («Социальная помощь и социальное обеспечение»)** в разрезе 20 регионов и видов социальных услуг.

Разработано по архитектуре **Pure Frontend (без бэкенда)** со статическими структурированными данными и поддержкой работы через протокол `file://`.

---

## Быстрый запуск

Просто откройте файл `index.html` двойным кликом в любом современном веб-браузере (Chrome, Edge, Firefox, Safari).

Никаких серверов, баз данных и установки Node.js не требуется!

## Ключевые возможности системы

### 1. Временной горизонт и динамика (2021–2025)
* **5 финансовых лет:** от 2021 года (3.98 трлн ₸) до 2025 года (6.05 трлн ₸, утвержденный план).
* **Метрика YoY (Year-over-Year):** темп прироста расходов год к году.
* **Макроэкономический контекст:** институциональные сводки по каждому периоду (внедрение Социального кодекса, создание областей Абай, Жетісу и Ұлытау, индексация базовых обязательств).
* **Автоматическое воспроизведение:** возможность проследить динамику межбюджетных трансфертов во времени.

### 2. Аналитические режимы визуализации
* **Потоки средств (Sankey):** движение средств от государственного бюджета через республиканский центр и акиматы в отраслевые программы.
* **Иерархическая декомпозиция (Sunburst):** радиальная структура расходов с возможностью детализации по уровням управления.
* **Сетевой граф связей:** топологическая модель взаимосвязей доноров, субвенционных областей и программ.
* **Сравнительный реестр регионов:** табличный аудит 20 регионов с подушевыми нормативами, сортировкой и полнотекстовым поиском.
* **Госзакупки (Реестр контрактов и поставщиков):** аудит договоров социальной сферы — заказчики (КГУ/акиматы), поставщики (ТОО, ИП, организации инвалидов ООИ по ст. 51 Закона РК), способы закупки, суммы и статусы исполнения.

### 3. Аналитический инспектор региона
* Выбор любого региона открывает боковую панель детализации без искажения масштаба диаграммы.
* Включает расчет отклонения от республиканского подушевого норматива, трансфертный статус (донор/субвенция), структуру расходов по 4 направлениям (АСП, медико-социальные учреждения, реабилитация, содействие занятости) и прямой переход к закупкам региона.
* Управление с клавиатуры (`Esc` для закрытия, стрелки для навигации по вкладкам).

### 4. Дизайн-система и цветовые режимы (Light Editorial & Dark Obsidian)
* Архитектура без шаблонных градиентов и избыточных теней.
* **Светлый режим (Light Editorial):** минеральная бумага (`#FAF9F5`), прецизионные разделители 1px, высокая контрастность для работы с числовыми массивами.
* **Темный режим (Dark Obsidian):** глубокая подложка (`#0D1117`), контрастные акценты для снижения нагрузки на зрение.
* Поддержка системных настроек `prefers-color-scheme` и ручного переключения.
* Шрифтовая триада:
  * **Newsreader** (антиква для редакционных заголовков и аналитических тезисов);
  * **Plus Jakarta Sans** (гротеск для управляющих элементов);
  * **JetBrains Mono** (моноширинный шрифт с табличными цифрами `tabular-nums` для финансовых показателей).

## Структура файлов проекта

```text
budget/
├── index.html                        # Аналитический веб-интерфейс (Pure HTML/JS)
├── README.md                         # Документация проекта
├── REDESIGN_PLAN.md                  # Спецификация и план редизайна
├── styles/
│   └── tokens.css                    # Токены дизайн-системы (Light Editorial & Dark Obsidian)
├── docs/
│   ├── audit.md                      # Первичный аудит и дефекты интерфейса
│   └── baseline_numbers.json         # Эталонные финансовые показатели (2021-2025)
├── data/
│   ├── regions.json                  # 20 регионов РК (КАТО, население, статус донор/субвенция)
│   ├── social_categories.json        # Классификатор Раздела 06 ЕБК РК
│   ├── budget_social_multiyear.json  # Полная база данных за 2021–2025 гг. (JSON)
│   ├── budget_data.js                # Офлайн-бандл данных для мгновенного запуска через file://
│   ├── procurement_data.json         # База договоров госзакупок соцуслуг (2021-2025, JSON)
│   └── procurement_data.js           # Офлайн-бандл госзакупок для запуска через file://
└── scripts/
    ├── generate_data.py              # Мульти-летний генератор и валидатор графовой модели
    ├── generate_procurements.py      # Генератор базы договоров госзакупок (goszakup.gov.kz)
    └── parse_minfin.py               # Модуль парсинга официальных Excel-отчетов Минфина РК (Форма 1-Н / 2-Н)
```

## Обновление данных (для разработчиков)

Для повторной сборки базы данных или парсинга свежих отчетов Минфина РК:
```bash
# Перегенерация пятилетки данных через uv:
uv run scripts/generate_data.py

# Или через стандартный Python:
python scripts/generate_data.py

# Парсер отчетов Минфина:
uv run --with pandas,openpyxl,httpx scripts/parse_minfin.py --file "путь_к_файлу.xlsx"
```
