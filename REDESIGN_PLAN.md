# План редизайна: Qazaqstan Public Finance Monitor

> Документ-инструкция для ИИ-агента (Claude Code, Cursor и т.п.). Выполняй фазы по порядку. После каждой фазы делай скриншоты и сверяйся с критериями приёмки. Не переходи дальше, пока критерии не выполнены.

## 0. Контекст проекта

Статичный сайт без бэкенда. Показывает социальные расходы бюджета РК (Раздел 06 ЕБК), 2021–2025, 20 регионов.

```
budget/
├── index.html            # ~1090 строк: разметка + Tailwind config + весь JS
├── data/
│   ├── budget_data.js               # офлайн-бандл (window-переменная), ~356 KB
│   ├── budget_social_multiyear.json # те же данные в JSON
│   ├── budget_social_2024.json
│   ├── regions.json
│   └── social_categories.json
├── scripts/generate_data.py, parse_minfin.py
└── README.md
```

**Стек сейчас:** Tailwind через CDN (play-скрипт), Apache ECharts 5.5 (CDN), Google Fonts (Newsreader, Plus Jakarta Sans, JetBrains Mono), инлайновые `onclick`.

**Четыре режима:** Sankey (потоки), Sunburst (иерархия), Graph (сеть связей), Реестр (таблица 20 регионов). Плюс таймлайн по годам с автопроигрыванием, инспектор региона (боковая панель), фильтр по региону, экспорт JSON.

**Ключевые функции JS (не ломать контракт):** `initApp, buildYearSelector, selectYear, updateYearContext, populateRegionDropdown, resetRegionFocus, populateQuickLedger, switchView, renderView, renderSankeyView, renderSunburstView, renderGraphView, populateRegistryTable, inspectRegionById, openInspectorCard, focusSelectedRegion, togglePlayTimeline, startPlayback, stopPlayback, exportActiveSlice, formatTenge`.

## 1. Жёсткие ограничения (не нарушать)

1. **Данные и расчёты не менять.** Файлы в `data/` и `scripts/` не трогать. Цифры на экране должны совпадать с текущими до знака.
2. **Функциональность сохранить полностью:** все 4 режима, таймлайн + автопроигрывание, инспектор, фильтр региона, поиск в реестре, экспорт JSON.
3. **Язык интерфейса: русский.** Тексты не переписывать без необходимости.
4. **Числа:** тенге через `formatTenge`, разделитель тысяч — неразрывный пробел, табличные цифры (`font-variant-numeric: tabular-nums`).
5. **Открытие двойным кликом (file://)** желательно сохранить. Если переходишь на сборку (Vite), оставь также готовую папку `dist/`, которую можно выложить на любой статический хостинг.
6. Перед началом сделай git-коммит текущего состояния (`git init`, если нет), чтобы можно было откатиться.

## 2. Диагностика текущего состояния (что улучшать)

Найдено по коду. Проверь на реальных скриншотах в фазе 1 и добавь свои наблюдения.

**Композиция и иерархия**
- До графика идут четыре горизонтальные полосы: шапка → выбор года → лид-абзац со статистикой → заголовок режима. Главная визуализация оказывается ниже первого экрана.
- Шапка `sticky` и содержит много элементов (бренд, таймлайн, 4 вкладки, экспорт). На мобильных она займёт пол экрана.
- Всё однотипное и мелкое: много текста 10–13 px, капс моно-подписи, тонкие рамки. Нет явного «героя» страницы.

**Типографика**
- Три шрифта, при этом моно используется для подписей, таблицы и чисел одновременно. Нужна чёткая ролевая схема.
- Размеры заданы произвольными значениями (`text-[10px]`, `text-[11px]`, `text-[13px]`) без шкалы.

**Цвет и компоненты**
- README описывает тёмную палитру (обсидиан `#080A0E`), а код реализует светлую «бумажную». Определись с одной концепцией (см. фазу 2).
- Кнопки, вкладки, инпуты и бейджи стилизованы вручную, единой компонентной системы нет.

**Технические проблемы, влияющие на качество**
- Tailwind Play CDN не предназначен для продакшена: вспышка неоформленного контента, лишний вес.
- Инлайновые `onclick`, всё в одном файле на 1000+ строк.
- Нет адаптивности графиков под мобильные, нет состояний загрузки/ошибки/пусто.
- README содержит локальные пути Windows (`c:\Users\...`): удалить.

## 3. Дизайн-направление

**Концепция: «data journalism» уровня FT / Bloomberg Graphics / The Pudding.** Не дашборд из карточек, а редакционная страница с одним сильным героем-графиком и аккуратным вторичным интерфейсом.

Принципы:
1. **Один герой на экран.** Главный график виден без прокрутки на 1440×900.
2. **Числа как типографика.** Крупные цифры с подписью вместо коробок-карточек.
3. **Сдержанность.** Максимум один акцентный цвет для интерфейса. Остальные цвета несут смысл (доноры / субвенции / категории).
4. **Ритм и воздух.** Единая сетка 8 px, чёткие интервалы между блоками.
5. **Никаких «ИИ-штампов»:** фиолетово-синих градиентов, стеклянных карточек с блюром, эмодзи вместо иконок, одинаковых скруглённых карточек-сеток, декоративных теней.

**Выбор темы (реши в фазе 2 и зафиксируй в токенах):**
- Вариант A — светлая редакционная (тёплая бумага, тёмный текст). Ближе к текущему коду.
- Вариант B — тёмная «терминальная» (как заявлено в README). Хорошо для Sankey и графа.
- Рекомендация: **A как основная + полноценная тёмная тема через CSS-переменные**, переключатель в шапке, стартует по `prefers-color-scheme`.

## 5. Фазы работ

### Фаза 1. Аудит и baseline (без изменений кода)

1. Запусти проект локально, сделай скриншоты каждого режима × каждого года × 4 ширины экрана. Сохрани в `docs/before/`.
2. Составь список проблем с приоритетами (P0 / P1 / P2) в `docs/audit.md`.
3. Зафиксируй метрики: Lighthouse, размер страницы, число запросов.
4. Запиши эталонные значения: суммы за каждый год, топ-регион, значения в реестре. Они нужны для проверки, что данные не сломаны.

**Приёмка:** есть `docs/before/`, `docs/audit.md`, файл с эталонными числами.

### Фаза 2. Дизайн-система (токены)

Создай `src/styles/tokens.css` (или блок `:root` в CSS). Все значения ниже — стартовые, уточни в Figma.

**Цвет (светлая тема):**
- `--bg`: тёплый off-white (≈ `#FAF9F5`), `--surface`: белый, `--surface-sunken`: чуть темнее bg
- `--text`: `#191918`, `--text-2`: `#4A4A45`, `--text-3`: `#787870` (проверь контраст ≥ 4.5:1 на bg)
- `--line`: `#E8E8E2`, `--line-strong`: `#D4D4CA`
- `--accent`: один синий из фирменного (≈ `#0082CA`, при необходимости затемни для текста)
- Смысловые: `--donor` (изумрудный), `--subvention` (терракотовый/янтарный), `--positive`, `--negative`
- Категориальная палитра для 4–6 направлений расходов: цветовой набор, различимый при дальтонизме (проверь в Viz Palette)

**Тёмная тема:** те же имена переменных, значения пересчитаны (не инверсия). Фон ≈ `#0E1116`, текст ≈ `#E8E6DF`, акцент светлее.

**Типографика (ролевая схема):**
- Заголовки и лид-текст: Newsreader
- Интерфейс, подписи, таблица: Plus Jakarta Sans (или Inter)
- Только крупные числа и колонки сумм: JetBrains Mono / tabular-nums
- Шкала: 12 / 14 / 16 / 20 / 28 / 40 / 56 px (значения-ориентиры). Минимальный размер основного текста 14 px, подписей 12 px. Никаких `text-[10px]`.
- Шрифты подключить локально (Fontsource / `@font-face` из `assets/fonts`), с `font-display: swap`, только нужные начертания и кириллица.

**Остальное:**
- Сетка и отступы: шаг 4/8 px; контейнер max 1280–1440 px
- Скругления: 2 значения (например 4 и 8 px)
- Тени: почти не использовать; вместо них линии и фон
- Анимации: 150–250 мс, `ease-out`; уважать `prefers-reduced-motion`

**Figma (если доступна):** создай страницу «Foundations» с Variables (цвет, типографика, отступы, режимы Light/Dark) и страницу «Components».

**Приёмка:** токены в одном месте, контраст проверен, в коде нет «магических» значений цвета и размеров вне токенов.

### Фаза 3. Компоненты

Спроектируй и реализуй (сначала в Figma или HTML-прототипе, затем в коде), со всеми состояниями (default, hover, focus-visible, active, disabled):

1. **Шапка:** компактная, высота ≤ 64 px. Слева название, справа переключатель темы и экспорт. Навигацию по режимам вынести из шапки в панель управления над графиком.
2. **Segmented control** для режимов (Потоки / Иерархия / Сеть / Реестр) с иконками Lucide.
3. **Timeline scrubber:** слайдер годов 2021–2025 с метками, кнопка play/pause, бейдж «план» для 2025, YoY-дельта.
4. **Stat-ряд:** 3–4 ключевые цифры крупным шрифтом с подписью и дельтой, без рамок-карточек.
5. **Инспектор региона:** боковая панель (drawer) на десктопе, bottom sheet на мобильных. Внутри: заголовок, статус (донор / субвенции), население, бюджет, на душу населения с дельтой к среднему, структура расходов как горизонтальный stacked bar + список.
6. **Таблица реестра:** sticky-шапка, выравнивание чисел по правому краю, сортировка по колонкам, inline sparkline или bar в ячейке «на душу», поиск, строка-hover, клик открывает инспектор.
7. **Select региона и поиск:** единый стиль инпутов, кастомный dropdown с поиском (combobox).
8. **Tooltip графиков:** единый стиль, тонкая рамка, моно-числа.
9. **Состояния:** skeleton загрузки, пустой результат поиска, ошибка загрузки данных.

**Приёмка:** все компоненты используют токены; в Figma (или в `/docs/components.html`) есть витрина компонентов.

### Фаза 4. Страница и раскладка

Целевая структура сверху вниз:

1. **Компактная шапка** (sticky, ≤ 64 px).
2. **Hero-блок:** заголовок (Newsreader, 40–56 px), одно предложение-лид с живыми числами, справа или снизу ряд из 3–4 ключевых цифр.
3. **Панель управления** (sticky под шапкой или над графиком): режимы + таймлайн + фильтр региона в одной линии.
4. **Главная визуализация** на всю ширину контейнера. Инспектор выезжает справа поверх/рядом, не сжимая график постоянно.
5. **Аннотации к годам:** заметки о Социальном кодексе, новых областях (Абай, Жетісу, Ұлытау), индексации выплат оформить как редакционные врезки рядом с графиком, а не строкой с обрезкой (`truncate`).
6. **Быстрый реестр / топ-регионы** и источники, методология, футер.

Брейкпоинты: 390 / 768 / 1024 / 1440. На мобильных: режимы — горизонтальный скролл или select, инспектор — bottom sheet, таблица — карточки строк или горизонтальный скролл с зафиксированной первой колонкой.

**Приёмка:** на 1440×900 главная визуализация и таймлайн видны без прокрутки; горизонтального скролла страницы нет ни на одной ширине.

### Фаза 5. Графики (ECharts)

Оформи через единый `chartTheme` (объект, привязанный к CSS-переменным; при смене темы переинициализировать).

- **Sankey:** сортировка узлов по величине, подписи только у крупных потоков (остальное в tooltip), градиент ленты от источника к получателю с умеренной прозрачностью, выделение связанных потоков при hover (`emphasis: focus: 'adjacency'`).
- **Sunburst:** тонкие белые/фоновые разделители, подписи только в достаточно крупных секторах, центр показывает выбранный узел и сумму; breadcrumb для навигации по уровням.
- **Graph:** уменьшить визуальный шум: размер узла по бюджету, цвет по статусу, подписи по hover или для топ-N; кнопка «сбросить раскладку».
- **Общее:** шрифты графиков из токенов, числа моно, единый формат тенге в подписях и tooltip, анимация появления 400–600 мс, `resize` через `ResizeObserver`, адаптивные настройки на узких экранах (меньше подписей).
- **Доступность:** под каждым графиком блок «Данные в виде таблицы» или `aria-label` с кратким выводом; не опираться только на цвет.

**Приёмка:** все три графика читаемы на 390 px и 1440 px, в обеих темах; tooltip не выходит за границы экрана.

### Фаза 6. Рефакторинг кода

1. Перенеси проект на **Vite + Tailwind (компилируемый)**; убери Tailwind CDN. Сохрани `dist/` для статического хостинга.
2. Раздели `index.html` на модули: `state.js`, `data.js`, `format.js`, `charts/{sankey,sunburst,graph}.js`, `components/*`, `styles/*`.
3. Убери инлайновые `onclick`, замени на `addEventListener`/делегирование.
4. Данные: загружать `budget_social_multiyear.json` через `fetch`; `budget_data.js` оставить как fallback для file://.
5. Шрифты и ECharts: локально (npm-пакеты), без CDN.
6. Добавь `README` с актуальной инструкцией, без локальных путей Windows и с правильным описанием палитры.

**Приёмка:** `npm run build` проходит; поведение идентично; эталонные числа из фазы 1 совпадают.

### Фаза 7. Доступность, производительность, полировка

- Клавиатура: все элементы достижимы Tab-ом, видимый `:focus-visible`, вкладки режимов по стрелкам, Esc закрывает инспектор.
- ARIA: роли `tablist/tab/tabpanel`, `aria-live` для смены года, `aria-pressed` у play.
- Контраст WCAG AA везде (текст ≥ 4.5:1, крупный ≥ 3:1).
- `prefers-reduced-motion`: отключить автопроигрывание анимаций, сохранить ручное переключение.
- Lighthouse: Accessibility ≥ 95, Performance ≥ 90 на десктопе.
- Мета: `<title>`, description, Open Graph-картинка (превью графика), favicon (₸).
- Печать: базовый `@media print` (опционально).
