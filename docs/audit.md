## 2. Выявленные проблемы и приоритизация (P0 / P1 / P2)

### Приоритет P0 (Критические архитектурные и UX-дефекты)
1. **Первый экран перегружен «служебными этажами»:** До графика пользователь видит 4 полосы (шапка $\rightarrow$ выбор года $\rightarrow$ лид со статистикой $\rightarrow$ заголовок режима). Главная визуализация (Sankey) вытеснена ниже сгиба экрана (1440×900).
2. **Шапка перегружена:** В шапке смешаны бренд, переключение 4 вкладок, кнопка воспроизведения и экспорт. На мобильных экранах она занимает половину высоты.
3. **Отсутствие темной темы при заявленной палитре:** В README была описана обсидиановая тема (`#080A0E`), а в интерфейсе реализована только светлая. Требуется единая токен-система с полноценным переключателем Light/Dark и уважением `prefers-color-scheme`.

### Приоритет P1 (Иерархия, компоненты и типографика)
4. **Хаос размеров шрифта:** Использование произвольных `text-[10px]`, `text-[11px]`, `text-[13px]` без системной шкалы. Моноширинный шрифт используется одновременно для подписей, бейджей и чисел.
5. **Инспектор региона сжимает рабочее пространство:** На десктопе боковая колонка постоянно отнимает 32% ширины у диаграммы, даже когда пользователь исследует общую структуру. Инспектор должен быть выдвижным элементом (Drawer), не мешающим обзору.
6. **Обрезанные тексты аннотаций (`truncate`):** Исторический контекст года обрезается многоточием, из-за чего теряется смысл законодательных реформ.

### Приоритет P2 (Доступность и полировка)
7. **Клавиатурная навигация:** Отсутствие четкого `focus-visible` на контролах годов, невозможность закрытия панелей клавишей `Esc`.
8. **Инлайновые обработчики событий:** Множественные `onclick="..."` в разметке затрудняют поддержку.
9. **Локальные пути Windows в документации:** В README присутствуют абсолютные пути `c:\Users\...`, что нарушает портативность.

## 3. Целевые метрики редизайна
- **Время до первого взаимодействия с графиком:** 0 скроллов на разрешении 1440×900.
- **Покрытие тем:** Полноценная светлая (основная) и темная (обсидиановая) темы.
- **Шкала типографики:** Фиксированная шкала 12 / 14 / 16 / 20 / 28 / 40 / 56 px.
- **Портативность:** Работа локально по протоколу `file://` без ошибок в консоли.
